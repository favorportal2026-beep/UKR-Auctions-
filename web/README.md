# Вебдодаток Аукціони.UA

Next.js 14 App Router. Supabase доступний лише із сервера; ключ не передається браузеру.

- `/`: активні/архів/усі; каталог по 48 лотів, сітка/список, сортування, критерії й статуси відбору.
- `/map`: усі результати фільтрів без фіксованого ліміту, кластери, вибір області, супутник, мобільний список.
- `/lots/<uuid>`: опис, ціни, площа, дати, статус джерела, кадастр, документи та нотатки.
- `/criteria`: створення/редагування/видалення/активність збережених пошуків.
- Статус і нотатки відкриваються з картки, деталей або попапа на мапі.
- `Перерахувати збіги`: серверна RPC обробляє всю таблицю однією транзакцією і зберігає notified.
- Час успішного збору, помилки й дата CSV показані над фільтрами.

## Запуск

```bash
cp .env.local.example .env.local
npm ci
npm run typecheck
npm run dev
```

Потрібні `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `NEXT_PUBLIC_MAPBOX_ACCESS_TOKEN`.
Необов’язковий `APP_PASSWORD` вмикає спільний пароль; без нього сайт доступний
за посиланням. Це одноосібний монітор: курація та нотатки спільні, акаунтів немає.
Серверні дії перевіряють парольну сесію, коли пароль задано.

## Vercel

Root Directory = `web`; ті самі env у Production та Preview.
Серверні ключі — секретні env, Mapbox `pk.` — публічний.
Схема/міграції зберігаються в `../supabase/` і застосовуються до деплою вебкоду.
Захищені sensitive env Vercel можуть повертати заглушки під час `env pull`;
для такого конфігу перевіряти інтеграцію на preview, а не підставляти заглушки локально.
